# PhoenixRecover / Recovery Platform

גרסה: 2.0  
תאריך: 12 באפריל 2026  
שפת עבודה: עברית  
סטטוס: פרויקט פעיל

## תיאור הפרויקט

פלטפורמת שחזור קבצים מקצועית, היברידית, מודולרית ורב־שכבתית, המאחדת מספר שיטות שחזור במקביל.

## טכנולוגיות

- **ליבה**: Rust
- **ממשק משתמש**: Tauri + React + TypeScript
- **מסד נתונים**: SQLite
- **שפות עזר**: Python, SQL

## מבנה הפרויקט

ראה [ARCHITECTURE_HE.md](docs/ARCHITECTURE_HE.md) לתיאור ארכיטקטורי מפורט.

## התחלה מהירה

1. התקן Rust ו-Node.js
2. שכפל את הריפו
3. הרץ `cargo build` ב-root
4. עבור ל-apps/desktop ו-Run `npm install` ו-`npm run dev`
